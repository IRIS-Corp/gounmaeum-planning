## [0.3.1] — 2026-10-07 · 글자 위계 · 토큰 정리

### 추가
- 디자인 토큰 · 컴포넌트를 레포에 포함: [`iris-ds/tokens/semantic.css`](../iris-ds/tokens/semantic.css) · [`iris-ds/iris-bundle.js`](../iris-ds/iris-bundle.js). 콘솔의 덮어쓰기 블록을 없애고 값은 토큰 파일에서만 옵니다.
- 내보내기 아이콘 `upload` · `download` (WDS 원본): [`iris-ds/assets/icons/`](../iris-ds/assets/icons/).
- [`docs/type-scale.md`](../docs/type-scale.md): 글자 7단계 표 (새 문서).
- [`docs/token-diff.md`](../docs/token-diff.md): WDS 원본과 다른 토큰 값 (새 문서).

### 변경
- 글자 위계 재설정: 섹션 제목 18/26/700, 항목 제목 16/24/600. 17px 섹션 제목 55곳 · 15px 항목 제목 65곳을 바꿨습니다.
- 순수 검정(#000) 제거. 가장 진한 글자는 `label-normal`(#171719). 탭 선택 글자 · 밑줄도 같이 바꿨습니다.
- 테두리 통일: 입력칸 · 검색창 · 드롭다운 · 필터 · 테두리 버튼 = #E1E2E4.
- 호버를 진하게 (8% · 12%).
- 대비 보정(WCAG AA 본문 4.5:1): `label-alternative` · `label-assistive` · 파랑 · 빨강 · 초록 · 주황 계열. 전체 목록은 `docs/token-diff.md`.
- 직접 넣은 색 189곳을 토큰으로 교체.
- 부의금 수수료 합계를 별도 줄로 분리.
- 서류 첨부 버튼 동작 수정.

### 고침
- 선택 창의 검색이 입력하는 대로 결과를 거릅니다. 본부 필터도 목록을 거릅니다 (0.1.0부터의 제한).

### 알려진 제한
- 데이터는 예시이며 저장되지 않습니다. 새로고침하면 처음 상태로 돌아갑니다.
- 정책 금액 · 한도 승인 규칙은 회사마다 다른 가안입니다.

## [0.3.0] — 2026-10-02 · 노션 결정 반영 · 1차 범위 정리

### 추가
- 부고장 테마 선택: 라이트 / 다크 미리보기 카드, 오른쪽 미리보기에 바로 반영.
- 임직원 "재직 상태" 열: 재직 · 휴직(기간) · 퇴사 처리 중.
- 복지 정책: 저장 버튼, "예시 금액 · 회사마다 정하는 값" 안내, 결재 규칙 토글 3개(정책 금액 안 자동 승인 · 초과 시 Owner 승인 · 휴직 중 신청), 경조 휴가 세부 설정 창.
- 내보내기 버튼 다운로드 아이콘 (montage-web `icon-download`를 아이콘 세트에 추가).
- 빈 상태: 리포트 · 결제 내역 · 마일리지 · 캘린더.

### 변경
- 권한을 Owner + 관리자 2단으로. 카드 등록 · 한도만 Owner.
- 법인카드: 한도 초과 승인 흐름 삭제, 월 한도 도달 시 사용 중지 + 문의.
- 경조사 진행 단계: 접수 → 결재 → 진행 → 완료.
- 경조금: 축의금 행사 당일 10:00 예약 송금, 부의금 승인 즉시.
- 화환: 축하 화환 N일 전 주문만, 상품 라인업 정리.
- 부고장: 공개 링크 발인 후 30일 만료. 서식 편집 대신 아이리스 부고장 사용.
- 거래처: 분류 · 수신 거부 삭제.
- 기록 · 정산: 큰 탭 → 필터 → 카드 안 하위 칩 순서로 위계 정리. 활동 로그 10행 페이지네이션.
- 페이지네이션 비활성 화살표의 회색 칸 제거.
- 경조 휴가를 표로, 기본 발송 상품 선택은 라디오만으로 표시.
- 확인 창 버튼 누르는 영역 44px.
- 마일리지: 요약 카드 3 · 잔액 · 내역 표. "화환 구매에 사용" 버튼과 "마일리지 사용처" 카드 삭제. 적립률(현재 4%) 변동 안내.
- 폰트를 파일에 포함 — 오프라인에서도 Pretendard로 표시 (파일 약 6MB).

### 삭제 (노션 근거 없음 · 1차 제외)
- 정책 변경 이력, 보고서 3종 내보내기, 활동 로그 내보내기, 부고장 임원 우선 발송, 방명록, 부고장 내 화환 버튼, 부고장 서식 편집.

### 알려진 제한
- 데이터는 예시이며 저장되지 않습니다.
- 선택 창 일부의 검색 · 본부 필터는 목록을 거르지 않습니다.

### 정의할 것 (회의에서 담당 정하기)
- 송금 수단(카드 / 계좌 · PG), 회사별 설정 위치(백오피스 / 콘솔), 임직원 동기화(CSV / HR 연동), 카카오 선물 · 답례품, 긴급 장례 온콜, 개인정보 보관 · 처리 시한, 진입 경로(랜딩 · 회사별 로그인 링크).

## [0.2.0] — 2026-09-30 · 로그인 흐름 · 컴포넌트 통일

### 추가
- 로그인 흐름: 휴대폰 번호 + 비밀번호 로그인, 처음 쓰는 사람은 휴대폰 인증 → 약관 동의 → 비밀번호 설정 → 완료. 새 기기 인증(이 기기 기억하기 30일), 비밀번호 재설정, 단계별 오류 안내. 정책은 [`docs/Login-flow.md`](../docs/Login-flow.md).

### 변경
- 왼쪽 위 회사 표시를 "고운마음"으로.
- 검색칸 · 할 일 목록 · 빠른 보내기 · 받는 사람 선택 · 상품 카드 · 선택 칩 · 라디오를 디자인시스템 컴포넌트(SearchField · ListCell · Card · Chip · Radio)로 교체.
- 자간을 글자 크기별 규칙 하나로 통일: 12 · 13px −0.004em, 14px −0.008em, 15 · 16px −0.012em. 목록 두 줄 글자의 줄높이 정리.
- 계좌번호 칸: 입력할 수 없는 상태를 흐리게 표시. 증빙 "파일 선택" 버튼이 동작.

### 알려진 제한
- 0.1.0과 같습니다 (폰트 온라인 로드 · 예시 데이터 · 가안 금액 · 일부 필터 미동작 · 남은 빈 상태).

## [0.1.0] — 2026-09-29 · 첫 프로토타입 공유

### 추가
- 단일 HTML 파일로 배포. 서버 없이 더블클릭으로 열립니다.
- 오른쪽 아래 **화면 상태** 토글: `데이터 있음 / 빈 상태` 전환. 보고 있던 페이지에서 바로 바뀌고, 마지막 선택을 기억합니다. 링크 끝에 `?empty=1`을 붙이면 빈 상태로 바로 열립니다.
- 빈 상태 홈: 시작 가이드 배너, "등록 전에 준비할 것" 3단계 체크(완료 · 미완료 표시, 모두 마치면 사라짐).
- 표 빈 상태: 권한 · 활동 로그 · 임직원 복지 비용 · 거래처 관리 비용.
- 설정 › 조직 · 관계: 본부별 팀 · 인원 펼침, 임직원 보기 연결.
- 경조금 보내기: 받는 분 계좌 직접 입력 + 예금주 조회.

### 변경
- 디자인시스템 이름을 IRIS 자체 이름으로 정리: 컴포넌트 묶음 `IrisDesignSystem`, 클래스 접두어 `iris-`. 설명 주석의 이전 이름을 모두 지움.
- 브라우저 탭 제목: "IRIS 콘솔 · 선진건설".
- 계좌는 항상 직접 입력. 받는 사람 카드의 "계좌 등록/미등록" 표시를 없애고, 요약의 입금 계좌는 입력한 값으로 표시.
- 설정 탭 순서 · 이름을 원본 기준으로 정리: 복지 정책 · 법인카드 · 문자·안내 · 조직·관계 · 회사 정보 · 권한.
- 보내는 사람 이름 · 부고장 공개 규칙을 회사 정보로 이동.
- 복지 정책: 지원하는 관계를 칸별 카드로, 기본 발송 상품을 리스트로.
- 진한 파랑(#0049B8)을 디자인시스템 기본 파랑(`primary-normal`)으로 통일.
- 체크 표시를 글자(✓) 대신 체크 아이콘으로.

### 알려진 제한
- 폰트: Pretendard를 온라인에서 불러옵니다. 인터넷이 없으면 시스템 한글 폰트로 표시됩니다.
- 데이터는 모두 예시이며 저장되지 않습니다. 새로고침하면 처음 상태로 돌아갑니다.
- 정책 금액 · 한도 승인 규칙은 회사마다 다른 가안입니다.
- 선택 창 일부의 검색 · 본부 필터는 목록을 거르지 않습니다.
- 남은 작업: 리포트 · 결제 내역 · 마일리지 · 캘린더 빈 상태.

### 정의할 것
기획 문서(PRD 초안 · 핸드오프 README)와 작업 기록에서 "미확인 · 확인 필요"로 남은 항목입니다. 정해지면 다음 버전에 반영합니다.

**정책 · 규칙**
- 정책 금액: 관계별 경조금 · 화환 금액. 현재 시안 금액(배우자 ₩300,000 / 부모 · 자녀 · 배우자 부모 ₩200,000 / 조부모 · 형제자매 ₩100,000)은 모두 가안이며 회사마다 정하는 값.
- 법인카드 한도 초과 승인: 기본 승인자는 Owner. 승인자 · 조건을 회사마다 다르게 둘지.
- 이체 실패 처리: "재시도 불가, 새로 작성해 보냄"은 시안 문구에만 있고 기획 문서에는 없음.
- 부고장 공개 링크: "발인 후 7일 만료 · 기록 2년 보관"은 시안 문구에만 있음. 개인정보 보관 기간 등 법적 · 보안 요구와 함께 확정 필요.
- 화환 반입 제한: 반입 불가 상품은 선택 불가로 처리하는 것이 확정인지.

**사용자 · 흐름**
- 임직원 경조 신청 채널: 앱 · 웹 중 무엇인지.
- 로그인 방식: 담당자가 콘솔에 들어오는 방법. 프로토타입에는 로그인 화면만 있음.
- 임직원 사번: 현재 시안은 사번을 쓰지 않음. 인사 시스템 동기화 · 동명이인 구분에 사번을 쓸지.

**범위 · 목표**
- 출시 범위: 1차 · 2차 구분.
- 성공 지표(KPI)와 목표 수치.
