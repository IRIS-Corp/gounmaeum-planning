## [0.1.0] — 2026-09-29 · 첫 프로토타입 공유

### 추가
- 단일 HTML 파일로 배포. 서버 없이 더블클릭으로 열립니다.
- 오른쪽 아래 **화면 상태** 토글: `데이터 있음 / 빈 상태` 전환. 보고 있던 페이지에서 바로 바뀌고, 마지막 선택을 기억합니다. 링크 끝에 `?empty=1`을 붙이면 빈 상태로 바로 열립니다.
- 빈 상태 홈: 시작 가이드 배너, "등록 전에 준비할 것" 3단계 체크(완료 · 미완료 표시, 모두 마치면 사라짐).
- 표 빈 상태: 권한 · 활동 로그 · 임직원 복지 비용 · 거래처 관리 비용.
- 설정 › 조직 · 관계: 본부별 팀 · 인원 펼침, 임직원 보기 연결.
- 경조금 보내기: 받는 분 계좌 직접 입력 + 예금주 조회.

### 변경
- 디자인시스템 이름을 IRIS 자체 이름으로 정리: 컴포넌트 묶음 `IrisDesignSystem`, 클래스 접두어 `iris-`. 설명 주석의 이전 이름을 모두 지움.
- 브라우저 탭 제목: "IRIS 콘솔 · 선진건설".
- 계좌는 항상 직접 입력. 받는 사람 카드의 "계좌 등록/미등록" 표시를 없애고, 요약의 입금 계좌는 입력한 값으로 표시.
- 설정 탭 순서 · 이름을 원본 기준으로 정리: 복지 정책 · 법인카드 · 문자·안내 · 조직·관계 · 회사 정보 · 권한.
- 보내는 사람 이름 · 부고장 공개 규칙을 회사 정보로 이동.
- 복지 정책: 지원하는 관계를 칸별 카드로, 기본 발송 상품을 리스트로.
- 진한 파랑(#0049B8)을 디자인시스템 기본 파랑(`primary-normal`)으로 통일.
- 체크 표시를 글자(✓) 대신 체크 아이콘으로.

### 알려진 제한
- 폰트: Pretendard를 온라인에서 불러옵니다. 인터넷이 없으면 시스템 한글 폰트로 표시됩니다.
- 데이터는 모두 예시이며 저장되지 않습니다. 새로고침하면 처음 상태로 돌아갑니다.
- 정책 금액 · 한도 승인 규칙은 회사마다 다른 가안입니다.
- 선택 창 일부의 검색 · 본부 필터는 목록을 거르지 않습니다.
- 남은 작업: 리포트 · 결제 내역 · 마일리지 · 캘린더 빈 상태.

### 정의할 것
기획 문서(PRD 초안 · 핸드오프 README)와 작업 기록에서 "미확인 · 확인 필요"로 남은 항목입니다. 정해지면 다음 버전에 반영합니다.

**정책 · 규칙**
- 정책 금액: 관계별 경조금 · 화환 금액. 현재 시안 금액(배우자 ₩300,000 / 부모 · 자녀 · 배우자 부모 ₩200,000 / 조부모 · 형제자매 ₩100,000)은 모두 가안이며 회사마다 정하는 값.
- 법인카드 한도 초과 승인: 기본 승인자는 Owner. 승인자 · 조건을 회사마다 다르게 둘지.
- 이체 실패 처리: "재시도 불가, 새로 작성해 보냄"은 시안 문구에만 있고 기획 문서에는 없음.
- 부고장 공개 링크: "발인 후 7일 만료 · 기록 2년 보관"은 시안 문구에만 있음. 개인정보 보관 기간 등 법적 · 보안 요구와 함께 확정 필요.
- 화환 반입 제한: 반입 불가 상품은 선택 불가로 처리하는 것이 확정인지.

**사용자 · 흐름**
- 임직원 경조 신청 채널: 앱 · 웹 중 무엇인지.
- 로그인 방식: 담당자가 콘솔에 들어오는 방법. 프로토타입에는 로그인 화면만 있음.
- 임직원 사번: 현재 시안은 사번을 쓰지 않음. 인사 시스템 동기화 · 동명이인 구분에 사번을 쓸지.

**범위 · 목표**
- 출시 범위: 1차 · 2차 구분.
- 성공 지표(KPI)와 목표 수치.
