## D27 · 경조금 계좌 · 서류 · 세무 (2026-10-14 확정)

### 1. 예금주가 받는 사람과 다를 때
- **임직원:** 막는다. 본인 명의 계좌만 허용 ("본인 명의 계좌가 아닙니다").
- **거래처 · 외부:** 막지 않는다. 받는 쪽은 상주 · 신랑 · 신부 같은 개인이고 가족 · 혼주 계좌인 경우가 많다.

### 2. 비교 기준
- **임직원:** 예금주 = 임직원 본인 이름 (띄어쓰기 · 앞뒤 공백 무시).
- **거래처 · 외부:** 이름 비교 없음. 예금주 조회로 계좌 존재와 예금주 이름만 보여 주고 "확인하고 송금"로 진행. 거래처명 · 담당자 이름은 비교 기준이 아니다.

### 3. 서류
- **임직원:** 회사 복지 정책(복리후생 정책 금액) + 본인 계좌 송금 기록.
- **거래처 · 외부:** 부고장 · 청첩장(링크 · 캡처 · 문자) **필수 첨부** + 송금 기록 + 확인한 사람 · 시각(활동 로그).
- 부고 · 청첩장에 계좌가 없으면 경조금 대신 화환만 보내도록 안내.

### 4. 세무 처리 (일반 기준 · 고객사 세무 담당 확인 필요)
| 받는 사람 | 계정 | 금액 기준 |
|---|---|---|
| 임직원 | 복리후생비 | 상한 없음 · 회사 규정 금액 (50만원 등) · 사회통념 초과분은 급여 간주 가능 |
| 거래처 · 외부 | 기업업무추진비(구 접대비) | 건당 20만원 · 초과 시 전액 불인정 · 화환 합산 해석 있음 |

- 거래처 한 건 금액이 20만원을 넘으면 경고만 한다 (막지 않음). 넘겨 보내도 법 위반은 아니며, 법인세 계산 때 그 건 전체가 비용으로 인정되지 않을 뿐이다. 임직원에는 띄우지 않음.
- 화환 합산 여부는 해석이 갈림 → 고객사 세무 담당 확인.

### 5. 용어
- 회사가 보내는 돈: **부의금 · 축의금**으로 통일.
- 부고장에 적는 상주 계좌: **부의금 계좌**.

## D31 · 설정 전 안내 (선행 조건) — 2026-10-16 확정

### 1. 막는 기준
| 하려는 일 | 먼저 필요한 것 |
|---|---|
| 경조사 등록 | 임직원 명단 + 복지 정책 시행 |
| 경조금 보내기 (받는 사람 임직원) | 복지 정책 시행 |
| 경조금 · 화환 보내기 (받는 사람 거래처) | 거래처 1곳 이상 등록 |
| 화환 보내기 (받는 사람 임직원) | 막지 않음 |

- 복지 정책은 화면에 들어간 것만으로 완료가 아님. **"규정 시행"을 눌러야 완료.**

### 2. 누르기 전 미리 알림
- 사이드바 "경조사 등록" 버튼은 항상 같은 모양 (아이콘 · 경고 문구 붙이지 않음). 남은 설정은 누르면 뜨는 설정 안내 창에서 보여 줌
- 경고 색(주황) 쓰지 않음 — 미설정은 오류가 아님
- 홈 시작하기 카드: 1 임직원 → 2 복지 정책 → 3 첫 경조사

### 3. 눌렀을 때
- **경조사 등록:** 작성 화면으로 넘어가지 않고 설정 안내 창. 빠진 항목을 번호 카드로 보여 주고 "설정하기 ›"로 해당 설정 화면 이동. 끝난 항목은 "완료"(누를 수 없음)
- **경조금 · 임직원:** 경조금 화면 안에 "복지 정책 설정하기" 안내
- **거래처 선택:** 받는 사람을 "거래처"로 바꾸면 "등록된 거래처가 없습니다" 창 → "거래처 등록하기" = 거래처 화면 + 추가 창

### 4. 설정을 마친 뒤
- 설정 화면 위 파란 줄 "설정을 마쳤습니다. 경조사 등록을 이어서 할까요?" → 하던 작업으로 복귀
- 거래처 등록 후에는 보내기 화면으로 자동 복귀하지 않음

## D32 · 발송별 증빙 첨부 — 2026-10-19 확정
| 발송 | 증빙 | 필수 조건 | 용도 |
|---|---|---|---|
| 경조금 · 거래처 | 부고장 · 청첩장 | 항상 | 세무 증빙 · 계좌 근거 |
| 화환 | 부고장 · 청첩장 | 거래처 · 직접 입력일 때 (등록된 경조사면 생략) | 용도(근조/축하) · 배송지 · 일정 · 리본 확인 |
| 부고장 · 직접 입력 | 사망진단서 · 장례식장 안내 · 부고 문자 캡처 | 항상 | 확인되지 않은 부고 발송 방지 |
| 부고장 · 등록된 경조사 | 없음 | — | 등록 · 승인 때 이미 확인 |
- 첨부 전에는 발송 버튼이 눌리지 않음

## D33 · 부고장 단건 발송 = 새 부고만 — 2026-10-19 확정
- 단건 발송의 부고장은 등록하지 않은 부고를 새로 입력해 보낼 때만 씁니다. "경조사에서 불러오기"는 없앱니다.
- 등록된 경조사(경조사 등록 · 임직원 신청 승인)의 부고장은 경조사 상세 "보낼 것"에서 보냅니다.
- 단건 부고장은 부고 증빙(D32)이 필수이고, 경조사 목록에는 추가되지 않습니다.

## D34 · 단건 발송 → 거래처 발송 — 2026-10-19 확정
- 사이드바 "단건 발송"을 "거래처 발송"으로 바꿉니다. 메뉴는 화환 · 경조금 두 개. 부고장은 메뉴에서 뺍니다.
- 받는 사람은 거래처 또는 직접 입력(외부인)만. 임직원 경조사는 경조사 등록에서 화환 · 경조금 · 부고장을 함께 처리합니다.
- 거래처 발송은 모두 부고장 · 청첩장 증빙이 필수입니다(D32).
- 부고장은 우리 회사 로고 · 발신 명의로 나가므로 거래처 부고에는 쓰지 않습니다. D33(부고장 단건 발송)은 이 결정으로 대체합니다.


## D35 · "단건 발송" 명칭 폐기 → "거래처 발송" (2026-10-16)
- D34로 단건 발송이 거래처 전용이 되어 두 이름이 같은 기능을 가리켰음.
- 시안 · 문서 전체에서 "단건 발송"을 "거래처 발송"으로 통일. 사이드바 · 상단 버튼 · 화면 제목 · 안내 문구 · 경조사 상세 기록 문구 포함.

## D36 · 거래처 발송 목록 · 상세는 거래처 기준 (2026-10-16)
- 화환 · 경조금 발송 내역의 받는 대상을 거래처(회사명 · 담당자 · 담당 본부)로 바꿈. 열 이름 "받는 분/받는 사람" → "받는 거래처".
- 부고장 발송 내역은 임직원 경조사 기준 그대로 (부고장은 경조사 상세에서만 발송).
