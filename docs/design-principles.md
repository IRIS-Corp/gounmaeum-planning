# IRIS 콘솔 · 디자인 원칙 (Figma 밖에서 설명이 필요한 것)

기준: `IRIS 콘솔 v3.1` · 값과 상태는 `component-states.md`, 토큰은 `design_handoff_iris_console/token-plan.md`를 따릅니다.

## 1. 인터랙션 원칙

| 원칙 | 규칙 |
|---|---|
| 화면당 파란 버튼 1개 | 그 화면의 핵심 행동만 solid primary. 나머지는 outlined assistive 또는 TextButton |
| 예외: 목록의 반복 행동 | 홈 "처리할 일"처럼 같은 종류의 행동이 여러 줄이면 줄마다 primary 허용 |
| 고르기 = 입력 + 검색 → 모달 | 사람 · 경조사 · 장례식장 · 받는 사람 · 담당자는 검색창 + "검색" 버튼(Enter 동일) → 결과 모달에서 고름 → 선택 카드 + "변경" |
| 목록 거르기 = 바로 거름 | 표 위의 검색창은 입력하는 즉시 표를 거름. 버튼 없음 |
| 결과 확인 | 가벼운 저장 → 토스트(2.4초). 돈이 나가거나 되돌릴 수 없는 행동(이체 · 발송 · 삭제) → 확인 Alert |
| 되돌릴 수 없는 행동 | 확인 창에서 negative 버튼 · 무엇이 사라지는지 한 문장 |
| 비활성 | 조건이 안 되면 버튼을 비활성 + 버튼 아래(또는 요약 패널)에 "남은 항목"을 적음 |
| 선택 표시 | 2px primary 테두리 + 옅은 파란 바탕. 선 하나만으로 선택을 나타내지 않음 |
| 호버 · 포커스 | 호버 = fill-alternative 덧칠 · 포커스 = 2px primary 링 · 누르는 범위는 행 전체 |
| 페이지 나누기 | 행 10개 초과일 때만 Pagination 표시 |

## 2. 예외 처리

| 상황 | 처리 | 위치 |
|---|---|---|
| 데이터 없음 | FallbackView(제목 · 한 줄 설명 · 필요하면 버튼 1개) | 모든 목록 · 표 |
| 검색 결과 없음 | 결과 모달 안에 "검색 결과가 없습니다" 한 줄 | 검색 모달 |
| 필수 입력 누락 | 입력칸 invalid + 아래 안내 문구 · 등록 버튼 비활성 | `validation-ui.md` |
| 예금주 불일치 · 이체 실패 | 재시도 없음 · 계좌 다시 입력 → 조회 → 새로 보내기 | 경조사 상세 |
| 법인카드 한도 초과 | 결제 보류 · 회사가 정한 승인자에게 요청 (승인자는 회사별) | 설정 › 법인카드 |
| 저장 안 하고 나가기 | "나가기 / 계속 작성" 확인 창 | 등록 · 보내기 · 복지 정책 |
| 로그인 실패 · 미등록 번호 | `login-flow.md` 6장 | 로그인 |
| 화환 반입 제한 | 제한 상품 비활성 · 대체 상품 안내 | 화환 보내기 |

## 3. 네이밍 컨벤션

| 대상 | 규칙 | 예 |
|---|---|---|
| 토큰 | Atomic `{램프}-{단계}` → Semantic `semantic.{용도}.{역할}` | `blue-45` → `semantic.primary.normal` |
| 컴포넌트 | 디자인 시스템 이름 그대로 · Figma 컴포넌트 = 코드 컴포넌트 1:1 | `Button`, `SearchField`, `ListCell` |
| Variant 축 | `variant` · `color` · `size` · `state` (Figma 속성 이름 = props 이름) | `Button / solid · primary · medium` |
| 화면 프레임 | `{순번} {화면명} / {상태}` | `03 경조사 목록 / 빈 상태` |
| 모달 | `M · {모달명}` | `M · 대상자 검색` |
| 문구 | `ux-writing.md` (명사형 버튼, "~할까요?" 확인) | |

## 4. 우선순위 기준

| 등급 | 기준 | 예 |
|---|---|---|
| P1 | 경조사 한 건을 등록 → 승인 → 발송 → 정산까지 끝내는 데 꼭 필요 | 로그인, 홈, 신청·승인, 경조사, 등록, 보내기 3종, 임직원, 설정(조직 · 복지 정책 · 권한) |
| P2 | 없어도 한 건은 처리되지만 운영 효율에 필요 | 리포트, 결제 내역, 캘린더, 활동 로그, 거래처 |
| P3 | 고객사 요청이 생기면 | 마일리지, 부고장 서식 세부, 자동 트리거 |
| 미정 | 노션 결정 보드에서 "미정 · 검토중" | `decisions.md` |
