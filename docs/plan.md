## 2. 핵심 흐름
### A. 경조사 (임직원 경조사)
1. 등록 — 관리자가 직접 등록하거나, 일반이 신청
2. 승인 — 일반이 신청한 건은 관리자의 **신청·승인 목록**에 들어감 → 승인 / 반려
3. 진행 — 경조사 상세에서 화환 · 경조금 · 부고장 발송
4. 완료 — 발송 · 송금 · 서류가 끝나면 완료, 기록 · 정산에 남음

### B. 거래처 발송 (거래처 경조사 · 1회성)
1. 작성 — 받는 거래처 · 화환/경조금 · 증빙(부고장 · 청첩장) 첨부 필수
2. 승인 — 일반이 작성한 건은 관리자의 신청·승인 목록에 들어감
3. 발송 — 승인되면 발송, 기록 · 정산에 남음
- 경조사로 등록되지 않음 · 부고장은 보내지 않음

### C. 장례케어 (MVP 제외 · 시안에만 둠)
- 임직원 · 가족이 기업 제휴가격으로 직접 결제 (199만 원부터)

## 3. 상태
| 대상 | 상태 |
|---|---|
| 경조사 | 접수 → 결재 대기 → 진행 → 완료 / 반려 · 취소 |
| 거래처 발송 | 작성 → 결재 대기 → 발송 → 완료 / 반려 |
| 송금 | 대기 → 완료 / 실패(계좌 재입력 후 새로 송금) |
| 화환 | 접수 → 배송 중 → 배송 완료 / 취소 |

## 4. 확정 정책 (요약)
- 증빙: 경조금 · 화환 모두 부고장 · 청첩장 첨부 필수
- 예금주: 이름 비교 없이 조회 결과를 보여 주고 확인
- 부의금 · 축의금은 수수료 포함 · 용어는 "축의금", "송금"
- 부고장 링크 발인 후 30일 만료 · 기본 테마는 설정에서 지정
- 본부 담당자 최대 3명
- 정책 금액 · 한도 승인자는 회사별 설정

## 5. 미정
- 일반이 등록한 경조사의 승인 기준 금액(자동 승인 여부)
- 송금 수수료 금액 (PG 확정 후)
- 일반에게 본인 건 외 조회 범위

## 6. MVP 범위
- 포함: 경조사 A · 거래처 발송 B · 신청·승인 · 임직원 · 조직 · 거래처 · 설정 · 리포트
- 제외: 장례케어 C, 마일리지
