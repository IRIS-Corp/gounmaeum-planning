# UX 라이팅 규칙

담당자가 화면을 열고 3초 안에 "지금 뭘 처리해야 하는지"를 알 수 있게 쓰는 것이 기준입니다.

## 원칙
1. **숫자와 기한 먼저.** "D-2 발인", "승인 대기 4건"처럼 급한 정도를 앞에 둡니다.
2. **행동은 동사로 끝냅니다.** 처리하기, 승인, 보내기. "진행", "관리"처럼 뜻이 넓은 말은 쓰지 않습니다.
3. **존댓말 평서문(-합니다/-입니다).** 느낌표, 감탄, "~해보세요" 같은 권유를 줄입니다.
4. **한 화면에서 같은 대상은 같은 이름.** 아래 용어 사전의 단어만 씁니다.
5. **띄어쓰기 고정:** 진행 중, 승인 대기, 발송 대기, 처리 완료.
6. **필수 표시:** 필수 입력은 라벨 뒤 빨간 `*`. "필수"라는 글자는 쓰지 않습니다.
7. **빈 상태:** "~이 없습니다" + 다음 행동 한 문장. 값이 없는 칸은 "—" 대신 플레이스홀더로 안내합니다.

## 용어 사전 (D29 · 2026-10-15)
| 쓰는 말 | 쓰지 않는 말 | 비고 |
|---|---|---|
| 대표 · 대표 계정 | Owner · 오너 · 루트(계정) | 회사에 1명 · 법인카드 한도 승인 |
| 관리자 | 어드민 · Admin | |
| 일반 | 뷰어 · Viewer | 조회 + 경조사 등록 · 단건 발송 가능 |
| 경조금 | — | 축의금 · 부의금을 묶는 말 |
| 축의금 | 축하금 | 결혼 · 출산 · 회갑 모두. 종류는 "출산 축의금"처럼 앞에 붙입니다 |
| 부의금 | 조의금 | 부고장의 계좌도 "부의금 계좌" |
| 송금 · 송금하기 | 이체 · 이체하기 | 송금 수수료 · 송금 실패 |
| 서류 | 증빙 | 서류 미제출 · 서류 요청 |
| 복지 정책 | 경조 규정 · 정책 v3 | 버전 숫자는 화면에 쓰지 않습니다 |
| 휴대폰 번호 | 전화번호 · 핸드폰 | 로그인 ID와 같은 말 |
| 거래처 | 협력사(대상 지칭 시) | 경조사를 보내는 상대 회사 |
| 경조사 | 케이스 · 건(목록 제목) | |
