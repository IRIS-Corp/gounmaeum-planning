## 결정 사항

### 임직원 등록
- 루트 계정은 100% 완료.
- CSV 일괄 등록 후 개별 추가 가능.
- **휴대폰 번호 = 기준 ID.** 중복 번호는 건너뛰고 신규만 추가, 기존 데이터는 삭제하지 않음.
- 번호 오입력으로 중복 임직원이 생길 수 있어 **삭제 기능**(사유 입력) 필요.
- 번호 변경은 관리자가 처리. 변경 시 기기 연결 해제 + 새 번호 재인증, **비밀번호 초기화 알림** 자동 발송.
- 신입 여부는 체크박스, 복지 안내 발송 여부도 등록 시 설정.
- 편집은 본부 · 직급뿐 아니라 전체 항목 허용.

### 조직관계 설정
- **조직관계 먼저 → 임직원 등록.** CSV 정합성 검증을 위해 본부/팀 값이 미리 있어야 함. 잘못된 본부/팀명은 업로드 오류.
- CSV 템플릿의 본부 · 팀 열은 등록된 값만 선택(그 외 편집 불가).
- 본부/팀 기본값 제공 후 수정 · 추가 가능하게 구성 (논의 중).
- 조직관계 화면에서 수정 · 삭제 · 담당자 지정. 담당자는 해당 본부 임직원 중 선택, 여러 본부 담당 가능.
- 본부 추가 시 담당자는 처음엔 비표시, 펼친 뒤 담당자 변경 노출.
- 미결: 조직관계 · 임직원 섹션 통합 여부(팀별 인원 수 파악 기능은 유지), 트리 구조 UI (편집 UX 우려).

### 관리자 역할
- Owner / 어드민 / 뷰어 → **Owner + 어드민 2단계.** 뷰어 제거.
- 초대 방식 → **본부 단위 담당자 지정.**
- 관리자 지정 화면의 역할 선택은 셀렉트박스 + 검색.

### HR 동기화
- HR API 연동은 현 단계에서 **제거** (HR 서비스 · 연동 범위 불명확).
- **마지막 업데이트 날짜**로 대체 (CSV · 개별 등록 모두 반영).

### 회사 정보
- 사업자 정보 변경은 검토 후 반영 (1~2일).
- 리본 문구는 **별도 메뉴**.
- 공개 규칙 · 부고장 등 회사 정보와 무관한 메뉴 **제거**.
- 명의 추가 = 문자 발송 시 쓰는 이름 값 (회사 정보에 유지).
