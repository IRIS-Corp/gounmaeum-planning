# 고운마음 · 로그인 정책 (v0.2)

> **확정 (2026-09-30)** — 루트 · 관리자 · 임직원 모두 같은 방식
> - **아이디:** 회사가 등록한 휴대폰 번호
> - **비밀번호:** 첫 로그인 때 휴대폰 인증 후 본인이 직접 만든다
> - **평소 로그인:** 휴대폰 번호 + 비밀번호
> - **인증번호가 필요한 때:** ① 첫 로그인 ② 비밀번호 재설정 ③ 처음 쓰는 기기 (루트 · 관리자)
>
> 표 안의 숫자는 가안이며 보안 · 비용 검토 후 확정한다.

## 0. 문의 답변 요약

| 문의 | 답 | 자세히 |
|---|---|---|
| 1-1 루트 계정에서 임직원 등록 방식 | ① 개별 등록 ② CSV 일괄 업로드 (③ 인사 시스템 연동은 추후) | 3장 |
| 1-2 등록 후 개인 계정 발급 방식 | **등록 = 계정 발급.** 등록한 휴대폰 번호가 아이디가 되고 상태는 `비밀번호 미설정`. 비밀번호는 발급하지 않고 본인이 첫 로그인 때 만든다. 등록 직후 첫 로그인 안내 문자 발송 | 3장 |
| 1-3 등록 시 필요한 정보 · 인증 방식 | 필수: 이름 · 휴대폰 번호 · 본부 · 팀 · 직급 · 입사일 / 선택: 이메일 · 생년월일. 인증은 등록된 휴대폰 번호로 SMS 인증번호 6자리 | 3장 |
| 2-1 루트 계정 로그인 | 휴대폰 번호 + 비밀번호. 처음 쓰는 기기에서는 인증번호 한 번 더 | 2 · 4장 |
| 2-2 임직원 개인 계정 로그인 | 휴대폰 번호 + 비밀번호 (새 기기 인증 없음 · 가안) | 2 · 4장 |
| 2-3 휴대폰 인증번호 로그인 적용 여부 | **평소 로그인에는 쓰지 않음.** ① 첫 로그인 ② 비밀번호 재설정 ③ 루트 · 관리자의 새 기기 확인에만 사용 | 4장 |
| 3 예상 흐름이 맞는지 | **맞습니다. 한 곳만 보완:** "휴대폰 인증번호 로그인"은 **첫 로그인 때만**이고, 이때 약관 동의 · 비밀번호 설정을 함께 한다. 이후에는 휴대폰 번호 + 비밀번호로 로그인한다 | 1장 |

**보완한 흐름:** 고객사 도입 문의 → 계약 체결 → 고운마음 백오피스에서 고객사 및 루트 계정 등록 → 루트 계정 **첫 로그인(휴대폰 인증 → 약관 동의 → 비밀번호 설정)** → 임직원 등록 → 각 임직원 **첫 로그인(휴대폰 인증 → 약관 동의 → 비밀번호 설정)** → 이후 휴대폰 번호 + 비밀번호 로그인

## 1. 전체 여정

| # | 누가 | 무엇을 |
|---|---|---|
| 1 | 고객사 | 도입 문의 · 계약 |
| 2 | 고운마음 운영자 | 백오피스에서 고객사 + 루트 계정(이름 · 휴대폰 번호) 등록 → 첫 로그인 안내 문자 |
| 3 | 루트 계정 | 첫 로그인: 휴대폰 인증 → 약관 동의 → 비밀번호 만들기 → 콘솔 |
| 4 | 루트 계정 | 경조 규정 · 결재 담당 설정, 관리자 등록 |
| 5 | 루트 · 관리자 | 임직원 등록 (개별 · CSV) → 첫 로그인 안내 문자 |
| 6 | 임직원 | 첫 로그인: 휴대폰 인증 → 약관 동의 → 비밀번호 만들기 → 임직원 신청 웹 |
| 7 | 모두 | 이후: 휴대폰 번호 + 비밀번호 (루트 · 관리자는 새 기기에서만 인증번호 한 번 더) |

## 2. 계정 종류

| 구분 | 아이디 | 등록하는 사람 | 로그인 후 | 새 기기 인증 |
|---|---|---|---|---|
| 루트 계정 (회사당 1) | 휴대폰 번호 | 고운마음 운영자 | 콘솔 전체 · 한도 승인 · 권한 이관 | 필수 |
| 관리자 | 휴대폰 번호 | 루트 계정 | 콘솔 (전 본부 / 본부 범위) | 필수 |
| 임직원 | 휴대폰 번호 | 루트 · 관리자 | 임직원 신청 웹 | 없음 |

한 사람이 관리자이면서 임직원이어도 계정은 하나(번호 하나)이고 역할만 추가한다.
계정 상태: `비밀번호 미설정` → `로그인 가능` → (`잠김`) → `퇴사`(로그인 차단, 기록 보존)

## 3. 임직원 등록과 계정 발급

**등록 방법** (콘솔 › 임직원)

| 방법 | 쓰는 때 | 동작 |
|---|---|---|
| ① 개별 등록 | 신규 입사자 한두 명 | 폼 입력 → 등록 |
| ② CSV 업로드 | 도입 초기 전체 명부 · 정기 갱신 | 템플릿 내려받기 → 업로드 → 검증(중복 · 형식 오류 표시) → 등록. 휴대폰 번호가 같으면 갱신, 퇴사일이 있으면 퇴사 처리 |
| ③ 인사 시스템 연동 | 추후 | 자동 동기화 |

**등록 정보**

| 항목 | 필수 | 비고 |
|---|---|---|
| 이름 | ● | |
| 휴대폰 번호 | ● | **로그인 아이디** · 회사 안에서 중복 불가 |
| 본부 · 팀 | ● | 경조 담당 범위 · 부고장 발신에 사용 |
| 직급 | ● | 경조금 규정 금액 계산에 사용 |
| 입사일 | ● | 근속 경조 · 신청 자격 |
| 이메일 · 생년월일 | — | 선택 |

**계정 발급**

1. 등록하는 순간 계정이 만들어진다 (아이디 = 휴대폰 번호, 상태 `비밀번호 미설정`).
2. "첫 로그인 안내 문자"가 자동 발송된다 (등록 화면에서 끌 수 있음 · 임직원 목록에서 재발송).
3. 비밀번호는 발급하지 않는다. 본인이 휴대폰 인증 후 직접 만든다 → 상태 `로그인 가능`.
4. 관리자는 임직원 목록에서 계정 상태를 보고, 미설정자에게 안내 문자를 다시 보낼 수 있다.

루트 계정은 고운마음 운영자가 백오피스에서 같은 방식(이름 · 휴대폰 번호)으로 등록하고, 관리자는 루트가 설정 › 권한에서 임직원 중 지정한다.

## 4. 화면 흐름

```
[로그인] 휴대폰 번호 + 비밀번호 → [로그인]
   · 미등록 번호            → "회사 담당자에게 등록을 요청하세요"
   · 비밀번호 미설정 계정    → "처음 로그인 시작하기"로 안내
   · 비밀번호 틀림 (n/5)    → "비밀번호 재설정"으로 안내 · 5회면 10분 잠금
   · 성공 · 루트/관리자 · 새 기기 → [새 기기 확인]
   · 성공 · 루트/관리자 · 기억된 기기 → 콘솔 홈
   · 성공 · 임직원 → 임직원 신청 웹
 링크: 비밀번호 재설정 · 처음 로그인하시나요? 휴대폰 인증으로 시작하기

[처음 로그인]  1/3 본인 확인 → 2/3 약관 동의 → 3/3 비밀번호 만들기 → 완료
   · 이미 비밀번호가 있는 계정 → "비밀번호 재설정"으로 안내
   · 첫 로그인을 마친 기기는 자동으로 '기억된 기기'

[비밀번호 재설정]  1/2 본인 확인 → 2/2 새 비밀번호 → 완료 → 로그인 화면
   · 비밀번호 미설정 계정 → "처음 로그인"으로 안내

[새 기기 확인]  등록 번호로 인증번호 자동 발송 → 6자리 → [확인]
   · "이 기기 기억하기 · 30일" 기본 체크
```

## 5. 규칙 (가안)

| 항목 | 가안 | 이유 |
|---|---|---|
| 비밀번호 | 8자 이상 · 영문 + 숫자 · 휴대폰 뒷자리 포함 불가 | 추측 어려운 최소 기준 |
| 비밀번호 실패 | 5회 틀리면 10분 잠금 → 재설정으로 해제 | 무차별 대입 방지 |
| 인증번호 | 6자리 · 3분 유효 · 재전송 30초 후 · 하루 10회 | 문자 비용 · 남용 방지 |
| 새 기기 기억 | 30일 (루트는 7일) | 결제 권한 계정 보호 |
| 로그인 유지 | 체크 시 30일 · 미사용 2시간이면 콘솔 로그아웃 | 공용 PC 대비 |
| 비밀번호 저장 | 단방향 암호화(bcrypt 등) · 평문 저장 · 발송 금지 | 기본 보안 |

## 6. 예외 상황

| 상황 | 처리 |
|---|---|
| 휴대폰 번호 변경 | 본인 변경 불가 → 관리자가 임직원 정보에서 변경 · 기억된 기기 전부 해제 · 새 번호로 재설정 |
| 휴대폰 분실 | 관리자에게 알림 → 기억된 기기 전부 해제 |
| 비밀번호 유출 의심 | 관리자가 "비밀번호 초기화" → 계정이 `비밀번호 미설정`으로 돌아가 첫 로그인 흐름 |
| 루트 담당자 퇴사 · 번호 변경 | 루트 권한 이관 (고운마음 운영자 확인) · 대행 관리자 1명 이상 권장 |
| 퇴사 | 관리자가 퇴사 처리 → 로그인 차단 · 경조 기록 보존 |

## 한 번호 · 여러 회사 (겸직 · 계열사) — 2026-10-07 확정: 허용
- 같은 휴대폰 번호를 다른 회사에서 등록할 수 있다. 사람(번호 · 비밀번호)은 하나, 회사별 소속 · 권한 · 데이터 · 경조 기록은 따로.
- 로그인: 번호 + 비밀번호 확인 → **소속 회사가 2곳 이상일 때만** "어느 회사로 들어갈까요?" 단계 → (새 기기면 기기 인증) → 콘솔.
- 회사가 1곳이면 이 단계 없이 바로 들어간다.
- 콘솔 안: 오른쪽 위 프로필 메뉴 "회사 전환" (2곳 이상일 때만 보임). 전환하면 홈으로 이동.
- 비밀번호는 사람 기준 하나 — 한 회사에서 바꾸면 모든 회사에 적용.
- B사 관리자가 이미 A사에 있는 번호를 등록해도 막지 않는다. 다른 회사 이름은 B사에 보이지 않는다.
- 시안 데모: 번호 `010-1234-5678` + 비밀번호 `0000` → 선진건설 / 한빛물산 선택 단계.
